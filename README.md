# Painel de Investimentos

Painel pessoal de acompanhamento da carteira (ações, FIIs, cripto, renda fixa), com cotações automáticas (brapi, CoinGecko, AwesomeAPI, Banco Central).

Este repositório contém **só o código**. Os dados ficam num repositório privado e são acessados com uma chave de acesso guardada no navegador de cada aparelho.
